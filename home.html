Welcome to the Games!

Choose a game below to play. Both games feature a soft UI/UX design and a dark mode toggle.

How to Play:

Select a game from the buttons below. Each game has its own set of rules:

  • Guess the Number: Try to guess a random number between 1 and 100 within 10 attempts.
  • Guess the Word: Try to guess the hidden word by guessing one letter at a time. You have a limited number of incorrect guesses.

You can toggle between light and dark themes using the button in the top right corner.
